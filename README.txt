WhatsApp Migrator — Android USB backup + experimental conversion

هذه نسخة تطوير، وليست بديلًا مكتملًا لـ Dr.Fone.

1. فك ضغط الحزمة بالكامل وشغل WhatsAppMigrator.exe على Windows x64.
2. نزّل Platform-Tools الرسمية من:
   https://developer.android.com/tools/releases/platform-tools
   بعد قبول شروط Google، ضع مجلد platform-tools كاملاً بجانب التطبيق.
   يلزم platform-tools/adb.exe وملفات DLL التابعة له.
3. وصّل أندرويد بكابل بيانات وفعّل USB debugging وافتح القفل ووافق على طلب RSA.
4. اضغط فحص أندرويد واختر الجهاز. unauthorized = وافق من الهاتف؛ offline = أعد الاتصال.
5. اختر مكان الحفظ واضغط نسخ أندرويد إلى اللابتوب.

ينسخ البرنامج ملفات WhatsApp المشتركة المتاحة (Databases وMedia) عبر ADB فعلي.
لا ينشئ نسخة كاملة للتطبيق، ولا يستخرج قاعدة خاصة أو مفتاح تشفير، ولا يستخدم root.
أنشئ نسخة محلية حديثة من داخل واتساب أولاً ولا تستخدمه أثناء النسخ.
وجود crypt15 أو crypt14 وحده لا يعني أن البيانات جاهزة للتحويل.
تتضمن النسخة تقرير ملفات وبصمات محلية، وليس إثبات صلاحية استعادة.

المرحلة الثالثة تنشئ مرشح تحويل للفحص فقط.
النقل والاستعادة إلى آيفون محظوران لأن التوافق لم يُثبت على أجهزة فعلية.
لا تستخدم المخرجات لاستعادة هاتفك الأساسي.

.NET وPython مضمنان؛ ADB وأداة wadecrypt غير مضمنين.
اختبارات البرنامج الآلية ليست تجربة هاتف حقيقية.
لا توجد بيانات وهمية أو محادثات اصطناعية داخل هذه الحزمة.
راجع README.md للتفاصيل.
