WhatsApp Migrator — تعليمات التشغيل
=====================================

المتطلبات المسبقة على جهاز المستخدم:
  1) Android Platform Tools (adb) في PATH
  2) iTunes (لنسخ iOS الاحتياطي — يأتي مع iTunes على Windows)
  3) pymobiledevice3 مثبت إذا كنت تستخدم نسخة Python (غير مطلوب إن استخدمت main_engine.exe المدمج)

الاستخدام:
  - اختر الاتجاه: أندرويد ← آيفون  أو  آيفون ← أندرويد
  - اختر نوع واتساب: العادي أو الأعمال
  - الصق مفتاح hex (64 حرف) من إعدادات النسخ الاحتياطي المشفر
  - حدّد المسارات المطلوبة
  - اضغط "بدء النقل"

ملاحظات مهمة:
  * التحويل من iOS إلى Android يتطلب صلاحيات Root على جهاز Android لدفع
    msgstore.db.crypt15 إلى /data/data/com.whatsapp/databases/.
  * تأكد من إيقاف واتساب على الجهازين قبل البدء.
  * احتفظ دائمًا بنسخة احتياطية من قاعدة البيانات الأصلية قبل التشغيل.
