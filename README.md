# WhatsApp Migrator — نسخة تطوير تجريبية

**هذا المشروع لا ينقل حاليًا كل بيانات واتساب إلى آيفون، وليس جاهزًا لاستعادة بياناتك الحقيقية.** المخرجات قاعدة وسيطة تجريبية لاختبار ربط المحادثات والرسائل والوسائط. توافقها مع قاعدة WhatsApp/Core Data الفعلية غير مثبت، ولا يكفي نجاح الاختبارات الآلية لإثباته.

## الإصلاحات

- ربط الرسائل بالمحادثات بخريطة معرّفات صريحة بدل افتراض تطابق أرقام أندرويد وآيفون، مع دعم ارتباط `chat` بجدول `jid`.
- ربط الوسائط بالرسائل من علاقات قاعدة المصدر، بما يشمل الملفات داخل مجلدات الصوت المتداخلة. لا يُخمّن الربط من أسماء الملفات.
- رفض المخططات غير المدعومة والرسائل اليتيمة والملفات المرتبطة المفقودة بدل إعلان نجاح ناقص. قد تُرفض قواعد صحيحة إذا اختلف مخططها عن المخططات المدعومة.
- فحص الأعداد والمفاتيح المرجعية وتحديث عدّاد الرسائل وآخر تاريخ للمحادثات.
- إزالة الحقن المكرر: **المحرك لا يحقن أي قاعدة أو وسائط الآن ولا يعدّل نسخة آيفون الاحتياطية.**
- إصلاح تحديث binary plist وNSKeyedArchiver مع الحفاظ على مراجع UID. أدوات الفهرس ليست اعتمادًا لصلاحية الاستعادة.
- إخفاء المفتاح في واجهة ويندوز وإرساله بمتغير بيئة، وعدم تسجيله ضمن الأوامر أو إظهار أخطاء التشفير الخام التي قد تحتويه.
- حذف تشفير crypt15 اليدوي ذي الترويسة التقديرية. فشل الأداة ينتج خطأ، لا ملفًا يُقدّم على أنه صحيح.
- إصلاح أخطاء C# المتعلقة بـ `ref` ومرجع `app.ico` المفقود وتمرير معاملات العملية، ومزامنة أحداث المحرك مع خيط الواجهة.

## القيود المهمة

لا توجد تجربة لاستعادة الناتج على آيفون أو فتحه في واتساب. مخطط iOS وقيم أنواع الرسائل ومعلومات Core Data والبيانات الوصفية لم تُعتمد. لا يوجد ضمان لنقل المجموعات والمشاركين والتفاعلات والرسائل المقتبسة وجهات الاتصال وسجل المكالمات والملصقات وكل خصائص واتساب. عدّ السجلات الوسيطة لا يعني نقل «كل بيانات واتساب».

الاتجاه العكسي والاستعادة أو الدفع إلى الأجهزة معطّلة من المحرك حتى تتوفر اختبارات توافق حقيقية. إنشاء بيانات فهرس جديدة دون قالب معروف غير مدعوم. لا تستعد المخرجات إلى هاتفك الأساسي.

## فحص محلي على نسخ من الملفات

يلزم Python 3.10 أو أحدث. لا يلزم ADB أو هاتف متصل لمعالجة SQLite مفكوكة التشفير. احتفظ بمدخلاتك الأصلية خارج مجلد الإخراج ولا ترفع المحادثات أو المفاتيح إلى GitHub.

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
python main_engine.py --direction android_to_ios \
  --android-db /copies/msgstore.db \
  --android-media /copies/Media \
  --ios-backup /copies/iphone-backup \
  --output-dir /separate/candidate-output
```

هذه أمثلة لمسارات تُستبدل بمساراتك، وليست ملفات مرفقة. تظل نسخة آيفون للقراءة فقط. يتضمن الناتج قاعدة مرشحة ووسائط مرتبطة وتقرير `migration_report.json` يصرّح أن التوافق غير مثبت. الحدث النهائي `candidate` وليس `success`. رمز الخروج 0 يعني اكتمال إنشاء المرشح فقط، لا النقل إلى آيفون. قد يُنشئ المحول مجلد ناتج فريدًا داخل مجلد الإخراج؛ راجع `output_db` في الحدث النهائي لمعرفة مساره.

ملفات `.crypt15` تتطلب `wadecrypt` ومفتاحك الصحيح. استخدم متغير البيئة `WHATSAPP_MIGRATION_HEX_KEY`؛ تجنّب `--hex-key` لأنه قد يظهر في سجل الطرفية أو قائمة العمليات. أداة `wadecrypt` الخارجية ما زالت تتلقى المفتاح كمعامل محلي، وقد يراه مستخدم ذو صلاحيات على الكمبيوتر أثناء تشغيلها. إخفاء السجلات لا يعني إخفاءه من النظام أو الذاكرة.

الأدوات الاختيارية في `requirements-tools.txt`. بناء PyInstaller لا يضمّن تلقائيًا الأدوات الخارجية أو ADB أو بيئة بايثون اللازمة لها. لا توجد اختبارات تحميل شاملة للقواعد الكبيرة بعد.

## بناء واجهة ويندوز

باستخدام .NET SDK 8 على ويندوز:

```bash
dotnet build WhatsAppMigrator.csproj --configuration Release
```

أو للبناء المتقاطع من Linux، أضف `-p:EnableWindowsTargeting=true`. تم بناء المشروع بنجاح عبر هذا المسار باستخدام SDK 8.0.426، دون أخطاء أو تحذيرات، لكن لم تُشغّل الواجهة على ويندوز ولم يُختبر هاتف فعلي. وفّر `main_engine.exe` بجانب التطبيق، أو مسار محرك التطوير وبيئة Python المناسبة.

## قبل اعتبار المشروع أداة نقل

1. فحص نسخ اختبار مُصرّح بها من إصدارَي واتساب وأندرويد وiOS المستهدفين، وتحديد مخطط Core Data ومعلوماته الوصفية بدل تخمينها.
2. بناء تحويل إصدار-محدد لكل الحقول والعلاقات والأنواع المطلوبة، مع بيان ما لا تدعمه الأداة.
3. الاستعادة إلى آيفون اختباري فقط مع نسخة أصلية قابلة للاسترجاع.
4. فتح واتساب والتحقق من النصوص العربية والمجموعات والصور والفيديو والصوت والوثائق والاقتباسات وبقية الأنواع، ومقارنة الأعداد والملفات قبل النقل وبعده.
5. تكرار الاختبار على الإصدارات المعلنة والقواعد الكبيرة وحالات انقطاع العملية وإعادة التشغيل. لا يُعلن الدعم إلا لما اجتاز الاختبارات.
